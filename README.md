🚉 Terminal-Identity : The Glitch Station

    "Dans cette gare, votre CV est votre visage, mais la musique est votre seule vérité."

Terminal-Identity est un projet de simulation immersive (ou un framework de jeu de rôle numérique) se déroulant dans un nœud de transit hybride. Ici, les voyageurs ne sont pas des individus, mais des profils "Linked-In" connectés par leurs compétences, évoluant dans un environnement où le réseau social et la réalité physique fusionnent.
🎭 Le Concept : Identités de Transit

Dans cette aérogare, l'anonymat n'existe pas, mais la vérité non plus.

    Linked-In IRL : Chaque passager est identifié par ses skills (Excel, Management, Design, Code).

    Le Jeu de Rôle : Choisissez votre masque. Incarnez une célébrité en transit, un mendiant visionnaire, une icône de mode ou un voyageur fantôme.

    Pseudonymat : Gérez vos réseaux sociaux en temps réel via l'interface de la gare, caché derrière votre alter-ego.

🛠️ L'Infrastructure Interactive

Le projet simule ou contrôle plusieurs points d'interaction dans la station :
Objet	Fonctionnalité Numérique
🎹 Le Piano de la Gare	Agit comme un terminal. Les notes jouées peuvent débloquer des segments du réseau ou modifier l'ambiance visuelle.
🥤 Distributeur de Boissons	Point d'injection pour le "hack". Un achat peut déclencher une fuite de données.
🎫 La Billetterie	Génère votre pseudonyme et votre rôle pour la durée du trajet.
🎨 L'Espace "Arts"	Zone de dépôt pour le street-art numérique et les performances de rue virtuelles.
⚡ Le Scénario : "The Pirate Plan" (Le Hack)

Le point culminant de l'expérience est l'événement Pirate Plan.
À un moment imprévisible, le réseau de la gare est compromis :

    Multi-Phone Broadcast : Une liste ciblée de passagers reçoit simultanément un faux plan de la gare sur leurs téléphones.

    Data Leak : Les secrets professionnels (ceux du profil "Linked-In") sont mélangés aux messages personnels.

    The Music Shift : L'ambiance sonore bascule brusquement vers une musique classique d'église ou une mélodie cryptique, signalant que le système a pris le contrôle.

🎵 La Musique comme "Seconde Maison"

La musique n'est pas un fond sonore, c'est l'architecture du projet.

    Architecture Sonore : Passage fluide entre l'agitation urbaine, le piano public et la solennité d'une église.

    Audio-Data : Certains fichiers musicaux contiennent des données cachées (stéganographie) nécessaires pour comprendre le "plan pirate".

💻 Stack Technique (Simulation)

    Real-time Communication : Socket.io pour la synchronisation des téléphones lors du hack.

    Identity Engine : Système de génération de rôles basé sur des APIs de réseaux sociaux.

    Audio Engine : Web Audio API / Max MSP pour la gestion de l'environnement sonore dynamique.

    Social Feed : Dashboard React affichant les flux sociaux "hacked" en temps réel.

In this station, we play a game with cards that look like social media profiles.

    Kings & Queens: High-visibility, loud profiles.

    The Numbers: The quiet, discrete ones (I prefer these).

🌿 Bienvenue dans mon Quotidien "Ovale"

Ce dépôt GitHub est le journal de bord d'une existence suspendue entre la simplicité du quotidien et l'ambition d'une scène internationale. C'est un mélange de musique classique, rock et pop, de jardinage et de saveurs de cuisine authentique.
🚉 La Gare : Le Point de Départ (et d'Ancrage)

Ma vie se structure autour d'une gare. Entre les magazines, le piano en libre-service et les distributeurs, un "Plan Pirate" m'oblige à rester sur place. C'est ici que tout se décide :

    Voyages Immobiles : Je parcours la France, l'Italie, l'Allemagne ou la Russie sans bouger, simplement en déchiffrant leurs partitions de musique.

    Abonnements Régionaux : Parfois, je m'évade avec un simple pass de bus ou de train local, explorant les frontières de ma région.

🃏 Le Jeu de Cartes "Profil"

On y joue à un jeu particulier où les cartes sont des profils sociaux :

    Roi & Reine : Les profils influents et exposés.

    Numéros : Les profils discrets, ceux que l'on ne remarque pas.

🤳 Entre Foi et Réseaux

Mon flux est envahi par des "icônes religieuses" qui défilent en format Short, balançant des citations sacrées entre deux vidéos virales. C'est le bruit de fond de mon salon, un espace que je transforme peu à peu en Salon Ovale, calquant mon emploi du temps sur celui des puissants de ce monde.
🎭 Les Deux Visages : Mode "Wonderful" & "Backstage"

    Show-off : Réserver des hôtels de luxe, jouer les "Bad Guys/Girls".

    L'Investissement : Je récupère tout ce qui peut servir à la scène, j'engage mes économies pour que le spectacle continue.
